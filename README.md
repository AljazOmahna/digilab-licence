# DigiLab — preverjanje licenc

Objava programa **DigiLab Licence** za preverjanje licenc DigiLab iQms prek spleta (GitHub Pages).

- `stanje.lic` — podpisan seznam stanja (preklicane licence in ključi)
- `n/`, `l/` — licence naprav in laboratorijev, vsaka šifrirana z oznako naprave oziroma kodo laboratorija

Datoteke zapiše DigiLab Licence (»Objavi zdaj«); ročno jih ne spreminjaj.
